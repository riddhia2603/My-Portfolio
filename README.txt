RIDDHI ARORA — PORTFOLIO / FIELD NOTES EDITION
================================================

A static portfolio website made with HTML, CSS, and vanilla JavaScript.
This edition uses a dark editorial canvas, offset photo framing, layered
project cards, electric pink/blue accents, and subtle pointer motion.

FILES
-----
index.html             Main page
style.css              Layout, visual design, responsive styling and animations
script.js              Navigation, scroll effects, typewriter, lightbox and motion
assets/favicon.svg     Browser tab icon
assets/images/         Profile photo, certificates and trophy

PREVIEW
-------
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

UPDATE YOUR EXISTING GITHUB PAGES WEBSITE
-----------------------------------------
You do NOT need to delete your GitHub repository or create a new one.

1. Extract this ZIP on your computer.
2. Open your EXISTING portfolio repository on GitHub.
3. Replace the existing index.html, style.css, and script.js with the versions
   from this folder. Upload the entire assets folder as well, keeping the same
   folder structure and filenames.
4. Commit the changes to the same branch GitHub Pages currently publishes
   (usually main). If prompted, confirm replacing the old files.
5. Open the existing website URL and refresh after GitHub Pages finishes deploying.
   If the old design remains, hard-refresh with Ctrl+F5.
